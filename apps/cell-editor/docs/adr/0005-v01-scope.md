# ADR-0005 — v0.1 scope: geometry + materials; tabs/shell/electrolyte/voltage deferred

**Status:** Accepted · 2026-06-11

## Context

`CellDesign` (the user's source-of-truth model) defines ~30 fields. Some
are geometric (drive the 3D scene), some are material (drive PyBaMM
simulation), some are operating conditions (voltage window). Building
panel UI for all of them in v0.1 is too much surface area; we want a
small, demonstrable v0.1.

## Decision

**v0.1 panel exposes only fields that drive geometry or affect
material-derived geometry.** Specifically:

| Field | Where in panel | Editable |
|---|---|---|
| `number_of_layers` | Stack | yes |
| `electrode_length` | Cell | yes |
| `electrode_width` | Cell | yes |
| `separator_thickness` | Separator | yes |
| `cc_p_thickness` | CathodeCurrentCollector | yes |
| `cc_n_thickness` | AnodeCurrentCollector | yes |
| `cathode_mass_loading` | Cathode | yes |
| `anode_mass_loading` | Anode | yes |
| `cathode_density` | Cathode | yes |
| `anode_density` | Anode | yes |
| `cathode_conductivity` | Cathode | yes (display only, no geometry effect) |
| `anode_conductivity` | Anode | yes (display only) |
| `separator_porosity` | Separator | yes (display only) |
| `cathode_theoretical_capacity` | Cathode | yes (display only) |
| `anode_theoretical_capacity` | Anode | yes (display only) |

Everything else is deferred.

## Deferred to v0.2+

The following are in `CellDesign` but **not in v0.1 panel**:

**Tab geometry** (`cc_p_tab_length`, `cc_p_tab_width`,
`cc_n_tab_length`, `cc_n_tab_width`, `cc_p_tab_y_coordinate`,
`cc_n_tab_y_coordinate`):
- v0.2: render tab as a small protrusion on each collector with these
  parameters editable. The current v0.1 collector template does not
  include a tab mesh.

**`cc_position`** (currently hardcoded "opposite"):
- v0.2: replace constant with a stack-level enum. "opposite" places the
  two collectors on opposite ends; "same" places them on the same end.

**Cell shell** (`shell_length`, `shell_width`, `shell_thickness`,
`wall_thickness`):
- v0.3: add a Shell node as a parent of Stack. Renders the outer
  rectangular housing.

**Electrolyte** (`init_conc_electrolyte`, `electrolyte_coefficient`):
- v0.3+: not currently modelled as a node. Could become a `Electrolyte`
  child of Cell with volume derived from shell internal dimensions and
  porosity.

**Voltage window** (`lower_voltage`, `upper_voltage`,
`voltage_at_0_soc`, `voltage_at_100_soc`):
- v0.3+: read-only metadata on Cell. Used by the future PyBaMM export.

**Particle-scale parameters** (`a_prefactor_p/n`, `cathode_D50`,
`anode_D50`, `init_conc_negative/positive`,
`*_theoretical_max_concentration`):
- v0.3+: not user-facing. Generated automatically from material
  choices when exporting to PyBaMM.

**Per-layer override** (varying one cathode instance vs another):
- Deferred indefinitely. If a future user needs it, we'd add an
  "advanced" mode that promotes one instance to a sub-node with its
  own parameters. ADR-0002 lists this as a possible evolution.

## Consequences

- Panel surface area: ~15 fields across 7 nodes. Manageable.
- The "select a layer template → see its panel" flow stays simple.
- The deferred fields are **not silently dropped** — they're documented
  in `CONTEXT.md` under "Out of Scope (v0.1)" so future contributors
  know they exist and where to add them.
- v0.1 is not a complete `CellDesign` editor — it's a focused
  geometry-and-material viewer/editor. The PyBaMM export will need to
  fill in deferred fields with defaults when exporting.
